# ADR-0003 配置收敛与模型正名

> 状态：已采纳 · 来源：历史挖掘（脱敏）

## 决定
模型正名为 **`qwen2.5-7b-instruct-abliterated.gguf`**；路径/文件名收敛到 **`shared/config.py` 的 `MODEL_PATH` / `MODEL_FILE`** 变量，**全局替换硬编码** `llama-3-8b-instruct.gguf`。

## 背景
文件名 `llama-3-8b-instruct.gguf` 实为 Qwen2.5-7B-abliterated，是"昨天 qwen 今天 llama"困惑的根源（见 `learned-rules` #3）。硬编码散落多处，改一处漏一处。

## 备选
- 保留旧名加注释说明 → 仍有混淆风险，弃用。
- 仅改用到处的字符串 → 改为单一来源变量，杜绝再漂移。

## 影响
- 模型引用单一来源，换模型只改一处。
- 与 ADR-0001 的软链路径一致。

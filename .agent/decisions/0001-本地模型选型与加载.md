# ADR-0001 本地模型选型与加载

> 状态：已采纳 · 来源：历史挖掘（脱敏）

## 决定
用本地 **qwen2.5-7b-instruct-abliterated.gguf**（ChatML）作教学模型；**复用 Ollama 已有 blob 软链**到 `models/`，不重复下载；用 **llama-cpp-python 进程内加载**（`Llama(model_path=...)`），开 Apple Silicon **Metal 全层 GPU**（`n_gpu_layers=-1`）。

## 背景
本地优先、无云 API 的教学定位；Apple M4 Pro 64GB；本机已装 Ollama 有现成 GGUF。需要可逐步加重试/工具调用/记忆的极简封装（`shared/llm.py`）。

## 备选
- llama-3-8b 路线 → 弃用（与教学示例/中文场景不如 qwen 顺）。
- Ollama HTTP 服务调用 → 弃用进程内方案（教学要看底层、避免"服务端帮你做了"的黑盒；进程内更透明）。
- HuggingFace 官方下载 → 改走国内镜像 `hf-mirror.com` / `modelscope`（网络）。

## 影响
- `shared/llm.py` 是 LocalLLM 极简封装，文本进文本出，按课逐步加能力。
- 模型路径软链复用，省下重复下载与磁盘。
- Metal 加速使本地交互式教学可行。

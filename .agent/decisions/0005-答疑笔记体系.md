# ADR-0005 答疑笔记体系与文档风格

> 状态：已采纳 · 来源：历史挖掘（脱敏）

## 决定
学习答疑沉淀为**根目录 `NN-主题.md` 编号笔记**（按学习相关性组织，与 `lessons/0X_*.md` 对应）；**勘误用删除线保留原错误内容 + 附修订记录**，不直接删；文档风格 = **最简技术文档**：禁比喻/修饰、不写"当前进度·下一步"类话术；笔记纳入 example 的原始 input/output；不记录琐碎翻译问题。

## 背景
用户学习导向，需可复习的干净笔记；多次因措辞带修辞/比喻被反对（见 `learned-rules` #11-12）。勘误若直接删会丢失"为什么曾经错"的学习价值。

## 备选
- 笔记与 lesson 混放 → 改为根目录编号，便于按学习线索检索。
- 勘误直接覆盖 → 改删除线保留，留下纠错轨迹。

## 影响
- 形成 `01-`…`05-` 系列答疑笔记。
- commit 用中文 conventional：`docs/i18n/chore(lessonN): …`。
